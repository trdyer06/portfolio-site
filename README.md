# Thomas Dyer's Software Portfolio

A website displaying my software development projects, built with React.

**Live site:** https://trdyer06.github.io/portfolio-site/

## Installation

Clone the repository

```bash
git clone https://github.com/trdyer06/portfolio-site.git
cd portfolio-site
```

Install dependencies and start the development server

```bash
npm install
npm run dev
```

Build for production

```bash
npm run build
```

## Tech Stack

- React - UI components
- Vite - Development server and build tool
- CSS3 - Styling
- GitHub Actions - Automatic deployment to GitHub Pages

## Features

- Introduction to Thomas
- Descriptions of each project
- Links to important pieces of each project
- Visual examples when applicable
