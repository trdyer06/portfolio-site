# Thomas Dyer's Software Portfolio

A website displaying my software development projects.

## Installation

Clone the repository

```bash
git clone https://github.com/trdyer06/porfolio-site.git
```

Open `index.html` in browser

## Tech Stack

- HTML5 - Structure
- CSS3 - Styling

## Features

- Introduction to Thomas
- Descriptions of each project
- Links to important pieces of each project
- Visual examples when applicable
